STEP 2: INSTALL DEPENDENCIES (2 minutes)
================================================================================

Open PowerShell and run:

  npm install

This downloads all packages. Takes 2-5 minutes depending on internet.

================================================================================
STEP 3: SETUP DATABASE (3 minutes)
================================================================================

Open MySQL command line:

  mysql -u root -p
  CREATE DATABASE Ember;
  EXIT

Then run:

  npx prisma generate
  npx prisma migrate dev --name init

This creates the database schema. You'll see:
  ✓ Generated Prisma Client
  ✓ Run migrations
  ✓ 10 tables created

================================================================================
STEP 4: START DEVELOPMENT (3 terminals)
================================================================================

Open 3 PowerShell windows and run these commands:

TERMINAL 1 (Frontend - Port 5173):
  npm run dev:vite

Wait for: "Local: http://localhost:5173/"

---

TERMINAL 2 (Backend - Port 3001):
  npm run server:dev

Wait for: "✓ Server running on http://localhost:3001"

---

TERMINAL 3 (Electron App):
  npm run dev:electron

This opens the desktop app with 3 windows visible.

================================================================================
STEP 5: CREATE YOUR FIRST SONG
================================================================================

In the Operator window:

1. Click "New Song" or "Import Song"
2. Enter:
   - Title: Amazing Grace
   - Artist: John Newton
   - Lyrics: (paste any hymn or song, separate verses with blank lines)
3. Click "Save Song"

Now you can:
  • Select song from sidebar
  • Click "Play" to display
  • Press Right Arrow or Space to navigate
  • Press B to blank screen
  • Press Ctrl+D to open display window

================================================================================
QUICK HELP
================================================================================

Q: How do I import Ember files?
A: Click "Import Song" → Select .pro file → Done!

Q: How do I see the display on my second monitor?
A: Press Ctrl+D. It automatically uses your 2nd display if available.

Q: What's the stage monitor for?
A: Press Ctrl+S to see speaker notes, next slide, and timer while presenting.

Q: Database password not working?
A: Update .env.local with correct password. Format:
   DATABASE_URL=mysql://root:YOUR_PASSWORD@localhost:3306/Ember

Q: Songs aren't loading?
A: Check backend is running (Terminal 2). Look for "✓ Server running"

Q: Changes not showing?
A: Try F5 refresh, or restart Electron (close and run again).

SUPPORT
================================================================================

If something isn't working:

1. Check console: Press F12 in main window
2. Check backend terminal for errors
3. Check .env.local settings
4. Delete node_modules and npm install again
5. Run: npx prisma migrate reset (⚠️ deletes data!)

For database issues:
  npx prisma studio
  Opens visual database editor at http://localhost:5555
